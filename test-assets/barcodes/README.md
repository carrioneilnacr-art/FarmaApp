# FarmaApp - Activos de Prueba: Códigos de Barra (Code 128)

Este directorio contiene las imágenes en formato **PNG de alta resolución** correspondientes a los **25 productos farmacéuticos** del catálogo inicial de **FarmaApp**.

Todos los códigos han sido generados en el estándar internacional **Code 128 (Subconjunto B)** con zonas de silencio (*quiet zones*) normalizadas y texto legible inferior para facilitar la identificación y escaneo en tiempo real mediante la cámara del smartphone Android.

## 🎯 Instrucciones de Uso para Pruebas y Demostración

Para probar la funcionalidad de lectura de códigos de barra en **FarmaApp**, puedes utilizar dos métodos:

### Método A: Proyección en Pantalla (Recomendado para Demos Rápidas)
1. Abre esta carpeta o las imágenes PNG individuales en tu laptop, monitor o tablet.
2. Abre la aplicación **FarmaApp** en tu teléfono Android (instalada mediante APK o en Expo Go).
3. Selecciona la opción **"Escanear Código"** o el botón flotante de escáner.
4. Apunta la cámara del smartphone hacia la pantalla a una distancia de **15 a 25 cm**.
5. Asegúrate de que el brillo de la pantalla sea moderado (evitar reflejos excesivos).
6. El visor detectará instantáneamente el código `BOT-XXXXXX` y abrirá la tarjeta del producto con su stock y precio en tiempo real.

### Método B: Impresión Física
1. Imprime las imágenes PNG en una hoja bond A4 estándar a escala 100%.
2. Puedes adherir las etiquetas a cajas o frascos de prueba para simular la experiencia real en botica.
3. El sensor de la cámara reconocerá las barras tanto en orientación horizontal como con inclinaciones leves.

## ⚙️ Regeneración de Códigos

Si necesitas volver a generar o modificar el catálogo de códigos de barras, ejecuta desde la raíz del proyecto:

```bash
node scripts/generate-barcodes.js
```
El script generará automáticamente los archivos PNG limpios en este directorio.
